🔔 Test Firebase Cloud Messaging

⚠️ Importante: Necesitas obtener el Server Key de Firebase Console:
  1. Ve a Firebase Console → Project Settings → Cloud Messaging
  2. Busca "Server key" en la sección "Cloud Messaging API (Legacy)"
  3. Si no aparece, habilita "Cloud Messaging API (Legacy)" primero
  4. Copia el Server Key y pégalo abajo

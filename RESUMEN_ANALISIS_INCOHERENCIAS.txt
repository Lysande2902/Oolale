   🔴 INCOHERENCIAS CRÍTICAS (Prioridad Alta)
═══════════════════════════════════════════════════════════════════════════════

1. 🔴 DOS TABLAS DE CONEXIONES (connections vs crews)
   ├─ Problema: Duplicación de funcionalidad
   ├─ Impacto: Datos inconsistentes, solicitudes perdidas
   ├─ Efecto: Contador muestra número diferente a lista real
   └─ Estado: ❌ PENDIENTE

2. 🔴 BLOQUEO NO FUNCIONA EN TODAS LAS PANTALLAS
   ├─ Problema: Filtro solo en algunas pantallas
   ├─ Impacto: Usuario bloqueado sigue visible
   ├─ Pantallas sin filtro:
   │  ├─ Rankings (Top Rated, Más Conectados, Más Activos)
   │  ├─ Eventos (lista y lineup)
   │  └─ Contrataciones
   └─ Estado: ❌ PENDIENTE

═══════════════════════════════════════════════════════════════════════════════
   🟡 INCOHERENCIAS IMPORTANTES (Prioridad Media)
═══════════════════════════════════════════════════════════════════════════════

3. 🟡 PATRONES DE NAVEGACIÓN MIXTOS
   ├─ Problema: 3 patrones diferentes (GoRouter, Navigator.push, pushNamed)
   ├─ Impacto: Código inconsistente, difícil de mantener
   └─ Estado: ❌ PENDIENTE

4. 🟡 DOS PANTALLAS DE PERFIL (ProfileScreen vs PublicProfileScreen)
   ├─ Problema: Duplicación de código y funcionalidad
   ├─ Impacto: Confusión sobre cuándo usar cada una
   └─ Estado: ❌ PENDIENTE

5. 🟡 ESTADÍSTICAS DE PERFIL INCONSISTENTES
   ├─ Problema: Perfil propio muestra "Música", ajeno muestra "Ratings"
   ├─ Impacto: UX confusa, información diferente
   └─ Estado: ❌ PENDIENTE

6. 🟡 MENSAJERÍA REQUIERE CONEXIÓN ACEPTADA
   ├─ Problema: Fricción innecesaria para comunicación
   ├─ Impacto: Oportunidades perdidas (contrataciones, colaboraciones)
   └─ Estado: ❌ PENDIENTE

7. 🟡 NOTIFICACIONES INCOMPLETAS (5/6 implementadas)
   ├─ Faltantes:
   │  ├─ Invitación a evento
   │  ├─ Evento cancelado/modificado
   │  ├─ Nuevo seguidor
   │  └─ Menciones y comentarios
   └─ Estado: ❌ PENDIENTE

8. 🟡 SISTEMA DE CALIFICACIONES LIMITADO
   ├─ Problema: Solo puedes calificar si estuvieron en mismo evento
   ├─ Impacto: Contrataciones y colaboraciones no se pueden calificar
   └─ Estado: ❌ PENDIENTE

📋 PRÓXIMOS PASOS (EN ORDEN)
═══════════════════════════════════════════════════════════════════════════════

  PASO 1: Abrir la guía
  ─────────────────────────────────────────────────────────────────────────────
  📄 Archivo: DESPLEGAR_EDGE_FUNCTION_PASO_A_PASO.md
  
  
  PASO 2: Instalar Supabase CLI
  ─────────────────────────────────────────────────────────────────────────────
  Comando: npm install -g supabase
  
  
  PASO 3: Iniciar sesión en Supabase
  ─────────────────────────────────────────────────────────────────────────────
  Comando: supabase login
  
  
  PASO 4: Inicializar proyecto
  ─────────────────────────────────────────────────────────────────────────────
  Comando: cd C:\Users\acer\3Warner\oolale_mobile
  Comando: supabase init
  
  
  PASO 5: Crear Edge Function
  ─────────────────────────────────────────────────────────────────────────────
  Comando: supabase functions new send-notification
  
  
  PASO 6: Copiar código
  ─────────────────────────────────────────────────────────────────────────────
  Copiar: supabase_edge_function_send_notification.ts
  Pegar en: supabase\functions\send-notification\index.ts
  
  
  PASO 7: Vincular proyecto
  ─────────────────────────────────────────────────────────────────────────────
  Comando: supabase link --project-ref TU_PROJECT_REF
  
  
  PASO 8: Configurar secrets
  ─────────────────────────────────────────────────────────────────────────────
  Comando 1: supabase secrets set FIREBASE_PROJECT_ID=oolale
  Comando 2: supabase secrets set FIREBASE_CLIENT_EMAIL=firebase-adminsdk-fbsvc@oolale.iam.gserviceaccount.com
  Comando 3: supabase secrets set FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----..."
  
  
  PASO 9: Desplegar función
  ─────────────────────────────────────────────────────────────────────────────
  Comando: supabase functions deploy send-notification
  
  Resultado: URL de la Edge Function
  Ejemplo: https://[tu-proyecto].supabase.co/functions/v1/send-notification
  
  
  PASO 10: Actualizar SQL
  ─────────────────────────────────────────────────────────────────────────────
  1. Ir a Supabase SQL Editor
  2. Ejecutar script con la URL de la Edge Function
  3. Probar con: SELECT test_notification_v1('tu-user-id'::uuid);

═══════════════════════════════════════════════════════════════════════════════

  Problema: Error al desplegar
  Solución: supabase functions deploy send-notification --debug
  
  Problema: No envía notificaciones
  Solución: supabase functions logs send-notification --follow
  
  Problema: Error de autenticación
  Solución: supabase secrets list (verificar que estén configurados)
